使用说明：

一、快捷键（默认值，可在 设置 > 按键设置 中自定义）
1.  Ctrl + H：隐藏/显示边框（同 F12）
2.  F12：     隐藏/显示边框
3.  F11:      全屏/退出全屏
4.  Esc:      退出全屏 / 隐藏窗口
5.  Ctrl + O：打开新文件
6.  Ctrl + F: 全文关键字查找，并跳转到指定位置
7.  Ctrl + T：置顶/取消置顶
8.  Ctrl + G: 全文进度百分比跳转
9.  Ctrl + →：快速跳转到下一章
10. Ctrl + ←：快速跳转到上一章
11. Ctrl + M：添加书签（书签列表中 Del/右键可删除）
12. Ctrl + E：编辑模式
13. →：       下一页
14. ←：       上一页
15. ↑：       向上滚动 N 行
16. ↓：       向下滚动 N 行
17. Ctrl + 鼠标滚轮：调节窗口透明度
18. 空格键：  开始/停止自动翻页

二、热键
1.  Alt + H： 快速隐藏/显示窗口

三、翻页
1.  鼠标左右键单击翻页（模式一）
2.  鼠标左键点击左右侧翻页（模式二）
3.  鼠标滚轮上下滚动
4.  鼠标侧键4：上一页
5.  鼠标侧键5：下一页

四、其他设置
1.  字体 / 颜色 / 背景图片
2.  显示设置：段距、压缩空行、章前分页等排版选项
3.  高级设置：自定义目录解析规则
4.  按键设置：快捷键与热键自定义

五、备注
1.  支持格式：txt / epub / mobi
2.  三种打开方式：Ctrl + O、菜单、文件拖拽
3.  还原初始状态：删除 Reader.exe 同目录下的隐藏文件 .cache.dat
