# Reader (aaron-mod)
A win32 txt/epub/mobi file reader

基于 binbyu/Reader 上游最新代码（v2.0.0.x）同步，并按个人需求定制：
- 保留：本地 txt / epub / mobi 阅读、版本更新检查
- 移除：在线小说（书源）、Web 阅读（legado 局域网同步）及 libhttps/openssl/wolfssl 依赖
- 本地新增：Ctrl+H 隐藏/显示边框、鼠标侧键4/5翻页

## 一、快捷键（默认值，可在 菜单 设置 > 按键设置 中自定义）
- Ctrl + H：隐藏/显示边框（同 F12）
- F12：     隐藏/显示边框
- F11:      全屏/退出全屏
- Esc:      退出全屏 / 隐藏窗口
- Ctrl + O：打开新文件
- Ctrl + F: 全文关键字查找，并跳转到指定位置
- Ctrl + T：置顶/取消置顶
- Ctrl + G: 全文进度百分比跳转
- Ctrl + →：快速跳转到下一章
- Ctrl + ←：快速跳转到上一章
- Ctrl + M：添加书签（菜单 Mark 为书签列表；在列表中选中后按 Del 或右键 Delete 可删除书签）
- Ctrl + E：编辑模式（可修改并保存当前页文本）
- Ctrl + +/-：字体放大/缩小
- →：       下一页
- ←：       上一页
- ↑：       向上滚动 N 行 (N: 设置 > 基本设置 > 文本滚动速度)
- ↓：       向下滚动 N 行
- Ctrl + 鼠标滚轮：调节窗口透明度
- Ctrl + Shift + 鼠标滚轮：透明度直接调到最高/最低
- 空格键：  开始/停止自动翻页（支持翻页/滚动两种模式）

## 二、热键
-  Alt + H： 快速隐藏/显示窗口 (可以在 设置 > 按键设置 自定义)

## 三、翻页
-  翻页模式一：(设置 > 基本设置 > 鼠标左右键点击翻页)
   -  鼠标左键单击：上一页
   -  鼠标右键单击：下一页
-  翻页模式二：(设置 > 基本设置 > 鼠标左键点击左右侧翻页)
   -  鼠标左键点击界面右侧1/3处：下一页
   -  鼠标左键点击界面左侧1/3处：上一页
-  鼠标滚轮：上/下 N 行
-  鼠标侧键4：上一页
-  鼠标侧键5：下一页
-  鼠标左右键同时按下：快速隐藏窗口（可关闭）

## 四、其他设置
-  设置 > 字体：   字体设置（可单独设置章节标题字体）
-  设置 > 颜色：   背景颜色设置（含取色器）
-  设置 > 背景图片：背景图片（拉伸/平铺/旋转平铺）
-  设置 > 显示设置：段距、压缩空行、章前分页、字符间距、首行缩进、Word wrap 等排版选项
-  设置 > 高级设置：自定义目录解析（关键字/正则）
-  设置 > 基本设置：翻页模式、滚动速度、自动翻页、最小化托盘、隐藏任务栏图标等
-  设置 > 按键设置：快捷键与热键自定义
-  设置 > 恢复默认

## 五、备注
-  支持格式：txt / epub / mobi（部分 KF7 格式 mobi 目录支持不佳）
-  三种打开方式：Ctrl + O、菜单 File > Open、文件拖拽
-  如需还原初始状态（或清除 File 菜单里的文件列表）：删除 Reader.exe 同目录下的隐藏文件 `.cache.dat`
-  边框隐藏时，鼠标左键按住页面顶部可拖动窗口
-  上游源码：https://github.com/binbyu/Reader
